# Algebra II Diagnostic Test
*Low Level Math / Algebra II*

This test samples the Algebra I skills that Algebra II builds on directly, to identify
which skills a student already has and which need review before starting the course.

## How to Use This Test

- Time limit: **40 minutes**. No calculator.
- Attempt every problem — if you're unsure, mark your best guess and move on rather than
  spending more than 2 minutes on any one question.
- This is a placement tool, not a graded exam. The answer key and full solutions live in
  [02-diagnostic-test-solutions.md](./02-diagnostic-test-solutions.md), together with a
  topic map so you can see exactly which skills to review.

## Problem 1: Multi-Step Linear Equations

Solve for $x$: $3(x - 4) + 2 = 5x - 10$

(A) -1  (B) 0  (C) 1  (D) 2  (E) 4

## Problem 2: Compound Inequalities

Solve for $x$: $-3 < 2x + 1 \le 7$

(A) $-2 < x \le 3$  (B) $-2 < x \le 4$  (C) $-1 < x \le 3$  (D) $-4 < x \le 3$  (E) $-2 < x \le 8$

## Problem 3: Absolute Value Equations

Solve for $x$: $|2x - 3| = 7$

(A) $x = 5$ only  (B) $x = -2$ only  (C) $x = 5$ or $x = -2$  (D) $x = 5$ or $x = 2$  (E) no solution

## Problem 4: Systems of Linear Equations

Solve the system:

$$
\begin{aligned}
2x + y &= 11 \\
x - y &= 1
\end{aligned}
$$

(A) $(3, 5)$  (B) $(4, 3)$  (C) $(5, 1)$  (D) $(6, -1)$  (E) $(4, -3)$

## Problem 5: Function Notation

If $f(x) = 2x^2 - 3x + 1$, find $f(-2)$.

(A) -13  (B) -1  (C) 3  (D) 15  (E) 17

## Problem 6: Domain of a Function

What is the domain of $f(x) = \dfrac{1}{x - 4}$?

(A) all real numbers  (B) $x \neq 0$  (C) $x \neq 4$  (D) $x \ge 4$  (E) $x \le 4$

## Problem 7: Slope-Intercept Form

Find the equation of the line with slope $-2$ that passes through $(1, 5)$.

(A) $y = -2x + 3$  (B) $y = -2x + 7$  (C) $y = 2x + 3$  (D) $y = -2x - 3$  (E) $y = -2x + 5$

## Problem 8: Function Transformations

The graph of $y = x^2$ is shifted 3 units right and 2 units down. Which equation matches
the new graph?

(A) $y = (x+3)^2 - 2$  (B) $y = (x-3)^2 - 2$  (C) $y = (x-3)^2 + 2$  (D) $y = (x-2)^2 - 3$  (E) $y = x^2 - 3x - 2$

## Problem 9: Exponent Rules

Simplify: $\dfrac{x^3 \cdot x^5}{x^4}$

(A) $x^2$  (B) $x^4$  (C) $x^7$  (D) $x^{12}$  (E) $x^{15}$

## Problem 10: Negative Exponents

Simplify: $\left(\dfrac{2}{x^{-2}}\right)^3$

(A) $\dfrac{8}{x^6}$  (B) $8x^6$  (C) $6x^{-6}$  (D) $\dfrac{6}{x^6}$  (E) $8x^{-5}$

## Problem 11: Multiplying Polynomials

Multiply: $(2x - 3)(x + 4)$

(A) $2x^2 + 5x - 12$  (B) $2x^2 - 5x - 12$  (C) $2x^2 + 11x - 12$  (D) $2x^2 + 5x + 12$  (E) $2x^2 - x - 12$

## Problem 12: Factoring a Trinomial

Factor: $2x^2 + 7x + 3$

(A) $(2x+1)(x+3)$  (B) $(2x+3)(x+1)$  (C) $(2x-1)(x-3)$  (D) $(2x+7)(x+1)$  (E) cannot be factored

## Problem 13: Factoring a Difference of Squares

Factor: $9x^2 - 25$

(A) $(3x-5)^2$  (B) $(3x-5)(3x+5)$  (C) $(9x-25)(x+1)$  (D) $(3x-25)(3x+1)$  (E) cannot be factored

## Problem 14: Solving Quadratics by Factoring

Solve for $x$: $x^2 - 2x - 15 = 0$

(A) $x = 3, 5$  (B) $x = -3, 5$  (C) $x = 3, -5$  (D) $x = -3, -5$  (E) $x = 5, 15$

## Problem 15: The Quadratic Formula

Which values of $x$ satisfy $2x^2 + 3x - 5 = 0$?

(A) $x = 1, -\dfrac{5}{2}$  (B) $x = -1, \dfrac{5}{2}$  (C) $x = 1, \dfrac{5}{2}$  (D) $x = -1, -\dfrac{5}{2}$  (E) $x = 5, -\dfrac{1}{2}$

## Problem 16: Vertex of a Parabola

What is the vertex of $f(x) = (x - 3)^2 + 4$?

(A) $(3, 4)$  (B) $(-3, 4)$  (C) $(3, -4)$  (D) $(4, 3)$  (E) $(-3, -4)$

## Problem 17: Simplifying Radicals

Simplify: $\sqrt{72}$

(A) $6\sqrt{2}$  (B) $8\sqrt{3}$  (C) $2\sqrt{18}$  (D) $36\sqrt{2}$  (E) $6\sqrt{12}$

## Problem 18: Rational Exponents

Which expression is equivalent to $x^{2/3}$?

(A) $\sqrt[3]{x^2}$  (B) $\sqrt{x^3}$  (C) $\sqrt[2]{x^3}$  (D) $\dfrac{2x}{3}$  (E) $3\sqrt{x^2}$

## Problem 19: Exponential Growth

A population starts at 200 and doubles every year, modeled by $P(t) = 200 \cdot 2^t$. What
is the population after 3 years?

(A) 600  (B) 800  (C) 1200  (D) 1600  (E) 4800

## Problem 20: Applied System of Equations

A theater sells adult tickets for \$8 and child tickets for \$5. It sells 100 tickets total
and collects \$650. How many adult tickets were sold?

(A) 40  (B) 50  (C) 60  (D) 70  (E) 80
