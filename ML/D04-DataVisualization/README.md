# D04 - Data Visualization

This folder introduces how to visualize the tables we built in [D01-Dataframe](../D01-Dataframe): turning raw rows and columns into plots that reveal patterns, distributions, and relationships.

## Course Goals

In this module, we will learn:

1. How to plot continuous data with `matplotlib.pyplot` (line plots, histograms, scatter plots, box plots)
2. How to build a two-way table for two categorical features and read what it tells us
3. How to visualize a two-way table as a bar chart or heatmap
4. How to combine pandas skills from D01 with the plotting skills from this module to explore a dataset end to end

## Lessons

1. [01-visualizing-continuous-data.md](./01-visualizing-continuous-data.md)
   Line plots, histograms, scatter plots, and box plots for continuous (numeric) data using `matplotlib.pyplot`
2. [02-two-way-tables-for-categorical-features.md](./02-two-way-tables-for-categorical-features.md)
   Building two-way tables with `pd.crosstab`, reading counts and proportions, and visualizing them as bar charts and heatmaps
3. [03-data-visualization-practice-set.md](./03-data-visualization-practice-set.md)
   Practice problems that combine D01 pandas skills with the visualization skills from this module

More lessons can be added later as the course grows.
