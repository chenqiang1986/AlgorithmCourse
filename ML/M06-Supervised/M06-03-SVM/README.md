# M06-03: Support Vector Machines
*ML / M06 — Supervised Learning*

Support vector machines (SVMs) choose a separating hyperplane with the
largest margin. This short sequence starts with the primal formulation and
then rewrites it as its Lagrange dual.

| Lesson | Topic |

| 2 | [The SVM Lagrange dual and the KKT conditions](02-svm-lagrange-dual.md) |

Throughout, labels are $y_i\in\{-1,+1\}$ and $\mathbf x_i\in\mathbb R^d$.
