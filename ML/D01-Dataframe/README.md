# D01 - NumPy and pandas DataFrames

This folder contains an introductory data lesson for NumPy arrays and pandas DataFrames.

## Course Goals

In this module, we will learn:

1. What a NumPy array is and why it is useful for numerical work
2. How pandas `Series` and `DataFrame` objects organize tabular data
3. How to select rows and columns with `loc`, `iloc`, and boolean filters
4. How to sort, clean, and transform data in a repeatable way
5. How to summarize data with `groupby`
6. How to solve hands-on coding tasks with small tables
