# Motion

This folder contains the Motion section of AP Physics 1.

## Course Goals

In this module, we will learn:

1. Describe motion using position, velocity, and acceleration.
2. Apply the constant-acceleration (uniform acceleration) kinematics equations to solve
   for an unknown quantity given the others.
3. Interpret position-time and velocity-time graphs of constantly accelerated motion.
4. Solve multi-step kinematics problems, including free fall and two-stage motion.
