# Practice: Comprehensive Review B (Lessons 1–7)
*Fundamental Math / Extra Practice / OperationRules*

Problems that combine several lessons at once: distributing with fractions, factoring, order of operations, complex fractions, and error spotting.

## Rules

This set **combines** the rules from Lessons 1–7 in the same problem. Calculate everything unless told otherwise.

- **Distributive law with fractions:** $a\left(\dfrac{b}{c}+\dfrac{d}{e}\right)=a\cdot\dfrac{b}{c}+a\cdot\dfrac{d}{e}$. If $a$ is a multiple of the denominators, the fractions disappear.
- **Combining like terms:** after expanding, add terms with the same letter part: $3x+2x=5x$.
- **Order of operations:** parentheses, then multiplication/division left to right, then addition/subtraction.
- **Complex fractions:** simplify top and bottom, or multiply both by the LCD.

Give answers **reduced**; use mixed numbers for improper numeric answers.
