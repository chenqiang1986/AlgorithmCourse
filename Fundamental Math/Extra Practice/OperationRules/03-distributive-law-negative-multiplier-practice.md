# Practice: Distributive Law with a Negative Multiplier
*Fundamental Math / Extra Practice / OperationRules*

**Do not calculate any results.** The goal is only to *rewrite* each expression using a rule. Leave products like $(-3) \times 4$ as they are. The only simplification allowed is removing a double negative (see Rule 4). Numbers and letters (variables) can both appear.

## Rules

1. **Distributive law:** $a(b + c) = ab + ac$ and $ab + ac = a(b + c)$. It still works when $a$ is negative: $(-a)(b + c) = (-a)b + (-a)c$.
2. **Leading minus sign:** $-(b + c) = (-b) + (-c)$ (a minus sign in front of parentheses means multiplying by $-1$).
3. **Subtraction ↔ Addition:** $a - b = a + (-b)$ (works in both directions).
4. **Double negative:** $-(-b) = b$, so $(-a)(-b) = ab$.

**Part A**

1. $(-3) \times 4 + (-3) \times 5$

**Part B**

6. $(-4)(9 + (-2)) = (-4) \times 9 + (-4)(-2) = (-4) \times 9 + 4 \times 2$
7. $-(a + (-b)) = (-a) + b$
8. $(-3)(x + (-5)) = (-3)x + (-3)(-5) = (-3)x + 3 \times 5$
9. $(-m)(n + (-p)) = (-m)n + (-m)(-p) = (-m)n + mp$
10. $-(x + (-y) + (-z)) = (-x) + y + z$

**Part C**

11. $(-5)(2 + 8)$
12. $-(a + b)$
13. $(-6)(x + y)$
14. $(-3)a + 3b = (-3)a + (-3)(-b) = (-3)(a + (-b)) = (-3)(a - b)$
15. $(-x)y + xz = (-x)y + (-x)(-z) = (-x)(y + (-z)) = (-x)(y - z)$

**Part D**

16. $(-2)(a + (-b) + c) = (-2)a + (-2)(-b) + (-2)c = (-2)a + 2b + (-2)c$
17. $-(5 + (-2a)) = (-5) + 2a = 2a + (-5) = 2a - 5$
18. $(-3)(a + (-4)) = (-3)a + (-3)(-4) = (-3)a + 3 \times 4 = 3 \times 4 + (-3)a = 3 \times 4 - 3a$
19. $(-4)a + 4 \times 7 = (-4)a + (-4)(-7) = (-4)(a + (-7)) = (-4)(a - 7)$
20. $(a + (-b))(-c) = a(-c) + (-b)(-c) = a(-c) + bc = bc + a(-c) = bc - ac$
