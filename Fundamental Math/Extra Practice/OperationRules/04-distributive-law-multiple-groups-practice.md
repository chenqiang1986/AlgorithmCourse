# Practice: Distributive Law — Expanding Longer Expressions
*Fundamental Math / Extra Practice / OperationRules*

**Do not calculate any results.** Expand every expression completely. Leave products like $7 \times 3$ as they are, and do **not** combine like terms. Numbers and letters (variables) can both appear.

## Rules

1. **Distributive law:** $a(b + c) = ab + ac$. It works for a negative multiplier too: $(-a)(b + c) = (-a)b + (-a)c$.
2. **Subtraction ↔ Addition:** $a - b = a + (-b)$. So a subtracted group is a group multiplied by a negative: $x - a(b + c) = x + (-a)(b + c)$.
3. **Double negative:** $(-a)(-b) = ab$.
4. **Several groups:** expand each group separately, then join the results in the same order.

**Worked example:** $7(3 + 5) - 4(2 - 3)$

$= 7(3 + 5) + (-4)(2 + (-3))$
$= 7 \times 3 + 7 \times 5 + (-4) \times 2 + (-4)(-3)$
$= 7 \times 3 + 7 \times 5 - 4 \times 2 + 4 \times 3$
