# Practice: Distributive Law — Rewriting Expressions
*Fundamental Math / Extra Practice / OperationRules*

**Do not calculate any results.** The goal is only to *rewrite* each expression using a rule. Leave products like $3 \times 4$ as they are. Numbers and letters (variables) can both appear.

## Rules

1. **Distributive law (expand):** $a(b + c) = ab + ac$, and also $(b + c)a = ba + ca$
2. **Distributive law (factor out):** $ab + ac = a(b + c)$ (the same rule read backwards)
3. **Subtraction ↔ Addition:** $a - b = a + (-b)$ (works in both directions)
4. **Distributing over a subtraction:** $a(b - c) = a(b + (-c)) = ab + a(-c) = ab - ac$
