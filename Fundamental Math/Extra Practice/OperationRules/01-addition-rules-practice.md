# Practice: Addition Rules — Rewriting Expressions
*Fundamental Math / Extra Practice / OperationRules*

**Do not calculate any results.** The goal is only to *rewrite* each expression using a rule.
Numbers and letters (variables) can both appear.

## Rules

1. **Subtraction ↔ Addition:** $a - b = a + (-b)$ (subtracting $b$ is the same as adding the opposite of $b$; it works in both directions)
2. **Commutative law:** $a + b = b + a$ (the order of the terms in an addition can be swapped)

**Part D**

16. $3 - 8 = 3 + (-8) = (-8) + 3$
17. $a - 5 = a + (-5) = (-5) + a$
18. $6 - x = 6 + (-x) = (-x) + 6$
19. $(-4) + y = y + (-4) = y - 4$
20. $(-b) + a = a + (-b) = a - b$
