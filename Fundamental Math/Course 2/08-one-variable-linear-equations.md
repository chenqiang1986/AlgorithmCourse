# Lesson 8: Solving One-Variable Linear Equations
*Fundamental Math / Course 2*

[Lesson 7](./07-algebraic-expressions-and-like-terms.md) covered simplifying expressions. This
lesson uses that skill to **solve equations** — find the value of $x$ that makes an equation
true — starting with one-step equations, then building up to two-step equations.

## 1. What Solving an Equation Means

An **equation** is a statement that two expressions are equal, like $x + 3 = 11$. **Solving**
an equation means finding the value of the variable that makes both sides equal.

Think of an equation as a balance scale: both sides weigh the same. Any move that's applied to
**both sides equally** keeps the scale level — and keeps the equation true.

## 2. Core Template: One-Step Equations — Addition and Subtraction

If a number is **added to or subtracted from** $x$, undo it by doing the opposite operation to
both sides.

$$x + a = b \quad\Longrightarrow\quad x = b - a \qquad\qquad x - a = b \quad\Longrightarrow\quad x = b + a$$

$$x + 5 = 12 \quad\Longrightarrow\quad x + 5 - 5 = 12 - 5 \quad\Longrightarrow\quad x = 7$$

Subtracting $5$ from both sides removes it from the left, leaving $x$ alone — and keeps the
equation balanced, since the same amount was removed from both pans.

## 3. Reading Example: One-Step Subtraction Equation

Solve $x - 8 = -3$.

Undo the subtraction by adding $8$ to both sides:

$$x - 8 + 8 = -3 + 8$$

$$x = 5$$

**Check:** substitute $5$ back into the original equation: $5 - 8 = -3$. True, so $x = 5$ is
correct.

**Non-obvious detail:** the same number ($8$) is added to *both* sides, not just the side with
the variable — matching Section 1's balance rule. Adding it to only one side would change which
value of $x$ makes the equation true.

## 6. Core Template: One-Step Equations — Multiplication and Division

If $x$ is **multiplied or divided** by a number, undo it with the opposite operation on both
sides.

$$ax = b \quad\Longrightarrow\quad x = \frac{b}{a} \qquad (a \ne 0) \qquad\qquad \frac{x}{a} = b \quad\Longrightarrow\quad x = ab$$

$$4x = 20 \quad\Longrightarrow\quad \frac{4x}{4} = \frac{20}{4} \quad\Longrightarrow\quad x = 5$$

## 7. Reading Example: One-Step Equation With a Negative Coefficient

Solve $-3x = 21$.

Undo the multiplication by dividing both sides by $-3$, using the integer division sign rules
from [Lesson 4](./04-integer-multiplication-division.md):

$$\frac{-3x}{-3} = \frac{21}{-3}$$

$$x = -7$$

**Check:** $-3(-7) = 21$. True.

**Non-obvious detail:** dividing both sides by a *negative* number is still just "doing the
same thing to both sides" — the sign rules from integer division apply exactly as they would
anywhere else, no special equation rule needed.

## 8. Class Practice 3: One-Step Multiplication Equation

### Problem

Solve: $7x = -35$

<details>
<summary>Solution</summary>

Divide both sides by $7$:

$$\frac{7x}{7} = \frac{-35}{7}$$

$$x = -5$$

The answer is **$x = -5$**.

</details>

## 9. Class Practice 4: One-Step Division Equation

### Problem

Solve: $\dfrac{x}{4} = -9$

<details>
<summary>Solution</summary>

Multiply both sides by $4$:

$$\frac{x}{4} \times 4 = -9 \times 4$$

$$x = -36$$

The answer is **$x = -36$**.

</details>

## 10. Class Practice 5: Word Problem — One-Step Equation

### Problem

A number decreased by $15$ equals $-6$. What is the number?

<details>
<summary>Solution</summary>

Let $x$ be the number. "Decreased by $15$" means subtract $15$:

$$x - 15 = -6$$

Add $15$ to both sides:

$$x = -6 + 15 = 9$$

The answer is **$9$**.

</details>

## 11. Core Template: Two-Step Equations

A two-step equation, like $2x + 3 = 11$, needs two undoing moves. **Undo addition/subtraction
first, then undo multiplication/division** — the reverse order from how the expression was
built.

$$ax + b = c \quad\Longrightarrow\quad ax = c - b \quad\Longrightarrow\quad x = \frac{c-b}{a}$$

$$2x + 3 = 11 \quad\Longrightarrow\quad 2x = 11 - 3 = 8 \quad\Longrightarrow\quad x = \frac{8}{2} = 4$$

This matches the balance-scale diagram in Section 1: subtract $3$ from both pans first, then
divide what's left in both pans by $2$.

## 12. Reading Example: Two-Step Equation

Solve $5x - 7 = 18$.

Undo the subtraction first — add $7$ to both sides:

$$5x - 7 + 7 = 18 + 7 \quad\Longrightarrow\quad 5x = 25$$

Now undo the multiplication — divide both sides by $5$:

$$\frac{5x}{5} = \frac{25}{5} \quad\Longrightarrow\quad x = 5$$

**Check:** $5(5) - 7 = 25 - 7 = 18$. True.

## 13. Reading Example: Two-Step Equation Needing Like Terms First

Solve $3x + 2x - 4 = 21$.

The left side has two $x$-terms — combine like terms ([Lesson 7](./07-algebraic-expressions-and-like-terms.md))
before undoing anything:

$$3x + 2x - 4 = 21 \quad\Longrightarrow\quad 5x - 4 = 21$$

Now solve as a normal two-step equation. Undo the subtraction first:

$$5x - 4 + 4 = 21 + 4 \quad\Longrightarrow\quad 5x = 25$$

Undo the multiplication:

$$x = \frac{25}{5} = 5$$

**Non-obvious detail:** combining like terms happens *before* the balance-scale moves begin —
it simplifies one side of the equation without touching the other, so it isn't an "undo" step
and doesn't need to be mirrored on the right side.

## 14. Class Practice 6: Two-Step Equation

### Problem

Solve: $3x + 5 = 20$

<details>
<summary>Solution</summary>

Undo the addition first:

$$3x + 5 - 5 = 20 - 5 \quad\Longrightarrow\quad 3x = 15$$

Undo the multiplication:

$$x = \frac{15}{3} = 5$$

The answer is **$x = 5$**.

</details>

## 15. Class Practice 7: Two-Step Equation With a Negative Coefficient

### Problem

Solve: $-4x + 9 = -7$

<details>
<summary>Solution</summary>

Undo the addition first:

$$-4x + 9 - 9 = -7 - 9 \quad\Longrightarrow\quad -4x = -16$$

Undo the multiplication:

$$x = \frac{-16}{-4} = 4$$

The answer is **$x = 4$**.

</details>

## 16. Class Practice 8: Two-Step Equation With Subtraction

### Problem

Solve: $6x - 11 = 13$

<details>
<summary>Solution</summary>

Undo the subtraction first:

$$6x - 11 + 11 = 13 + 11 \quad\Longrightarrow\quad 6x = 24$$

Undo the multiplication:

$$x = \frac{24}{6} = 4$$

The answer is **$x = 4$**.

</details>

## 17. Class Practice 9: Two-Step Equation Needing Like Terms First

### Problem

Solve: $4x - x + 2 = 14$

<details>
<summary>Solution</summary>

Combine the like terms on the left first:

$$4x - x + 2 = 14 \quad\Longrightarrow\quad 3x + 2 = 14$$

Undo the addition:

$$3x + 2 - 2 = 14 - 2 \quad\Longrightarrow\quad 3x = 12$$

Undo the multiplication:

$$x = \frac{12}{3} = 4$$

The answer is **$x = 4$**.

</details>

## 18. Class Practice 10: Word Problem — Two-Step Equation

### Problem

A taxi charges a flat $\$3$ fee plus $\$2$ per mile. A ride costs $\$17$ in total. How many
miles was the ride?

<details>
<summary>Solution</summary>

Let $x$ be the number of miles. The total cost is the flat fee plus $\$2$ per mile:

$$2x + 3 = 17$$

Undo the addition first:

$$2x + 3 - 3 = 17 - 3 \quad\Longrightarrow\quad 2x = 14$$

Undo the multiplication:

$$x = \frac{14}{2} = 7$$

The answer is **$7$ miles**.

</details>

## 19. Class Practice 11: Word Problem — Consecutive Perimeter

### Problem

A rectangle's length is $3$ more than its width. Its perimeter is $26$. Let $x$ be the width,
and write an equation for the perimeter; then solve for $x$.

<details>
<summary>Solution</summary>

The length is $x + 3$. A rectangle's perimeter is twice the width plus twice the length:

$$2x + 2(x+3) = 26$$

Distribute ([Lesson 7](./07-algebraic-expressions-and-like-terms.md)) and combine like terms:

$$2x + 2x + 6 = 26 \quad\Longrightarrow\quad 4x + 6 = 26$$

Undo the addition:

$$4x + 6 - 6 = 26 - 6 \quad\Longrightarrow\quad 4x = 20$$

Undo the multiplication:

$$x = \frac{20}{4} = 5$$

The answer is **$x = 5$** (width $5$, length $8$).

</details>

## 20. Common Mistakes

### 20.1 Undoing multiplication/division before addition/subtraction

In $2x + 3 = 11$, dividing everything by $2$ first (getting $x + 1.5 = 5.5$) works but makes
the numbers messier and easy to mishandle. Undo addition/subtraction first, then
multiplication/division — the reverse of how the expression was built (Section 11).

### 20.2 Applying the operation to only one side

Adding, subtracting, multiplying, or dividing must happen to **both sides** of the equation, not
just the side with the variable. Changing only one side breaks the balance and gives a wrong
value of $x$.

### 20.3 Forgetting to combine like terms before solving

In $3x + 2x - 4 = 21$, trying to "undo" $3x$ and $2x$ separately skips a step. Combine like
terms first ([Lesson 7](./07-algebraic-expressions-and-like-terms.md)) so the equation has just
one $x$-term before applying the balance-scale moves.

### 20.4 Sign errors when undoing a negative term

In $-4x + 9 = -7$, subtracting $9$ from both sides gives $-4x = -16$, and dividing by $-4$
(not $4$) gives $x = 4$. Dividing by the wrong sign is a common slip — always divide by the
coefficient exactly as written, sign included.

## 21. Key Takeaways

- Solving an equation means finding the value of $x$ that makes both sides equal — think of it
  as a **balance scale** that must stay level.
- **One-step equations:** undo addition/subtraction with the opposite operation, or undo
  multiplication/division with the opposite operation, applied to both sides.
- **Two-step equations:** undo addition/subtraction **first**, then undo
  multiplication/division — the reverse order from how the expression was built.
- **Combine like terms before solving** if either side of the equation has more than one term
  of the same type.
- **Check every answer** by substituting it back into the original equation.
