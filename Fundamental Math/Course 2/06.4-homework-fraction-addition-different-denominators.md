# Homework: Lesson 6.4 — Fraction Addition and Subtraction
*Fundamental Math / Course 2*

This homework practices [Lesson 6.4](./06.4-fraction-addition-different-denominators.md).
Leave products and sums in factor form (write $3\times5$, not $15$) and use only the numbers
already in each problem. Part B also uses the multiplication and reduction skills from
[Lesson 6.3](./06.3-fraction-multiplication-division-reduction.md).

## Part A: Addition and Subtraction

### Problem 1

Write as one fraction: $\dfrac{2}{9}+\dfrac{5}{9}$

<details><summary>Solution</summary>

$$\frac{2+5}{9}$$

</details>

### Problem 2

Write as one fraction: $\dfrac{7}{15}-\dfrac{4}{15}+\dfrac{2}{15}$

<details><summary>Solution</summary>

$$\frac{7-4+2}{15}$$

</details>

### Problem 3

Write as one fraction: $\dfrac{3}{5}+\dfrac{2}{7}$

<details><summary>Solution</summary>

$$\frac{3\times7+2\times5}{5\times7}$$

</details>

### Problem 4

Write as one fraction: $\dfrac{4}{9}-\dfrac{5}{8}$

<details><summary>Solution</summary>

$$\frac{4\times8-5\times9}{9\times8}$$

</details>

### Problem 5

Write as one fraction: $\dfrac{5}{6}+\dfrac{7}{6\times5}$

<details><summary>Solution</summary>

$$\frac{5\times5+7}{6\times5}$$

</details>

### Problem 6

Write as one fraction: $\dfrac{1}{2\times3}+\dfrac{1}{3\times7}$

<details><summary>Solution</summary>

The common denominator is $2\times3\times7$:

$$\frac{1\times7+1\times2}{2\times3\times7}$$

</details>

### Problem 7

Write as one fraction: $\dfrac{3}{4}-\dfrac{1}{4\times5}-\dfrac{2}{5}$

<details><summary>Solution</summary>

$$\frac{3\times5-1-2\times4}{4\times5}$$

</details>

## Part B: Mixed Operations

### Problem 8

Write as one fraction: $\dfrac{2}{7}+\dfrac{3}{5}\times\dfrac{1}{7}$

<details><summary>Solution</summary>

$$\frac{2}{7}+\frac{3\times1}{5\times7}=\frac{2\times5+3\times1}{5\times7}$$

</details>

### Problem 9

Write as one fraction: $\dfrac{\quad\dfrac{1}{3}+\dfrac{1}{4}\quad}{\quad\dfrac{1}{5}\quad}$

<details><summary>Solution</summary>

$$\frac{1\times4+1\times3}{3\times4}\times\frac{5}{1}=\frac{(1\times4+1\times3)\times5}{3\times4\times1}$$

</details>

### Problem 10

Write as one fraction: $\left(\dfrac{5}{6}-\dfrac{1}{6}\right)\div\dfrac{7}{9}$

<details><summary>Solution</summary>

$$\frac{5-1}{6}\times\frac{9}{7}=\frac{(5-1)\times9}{6\times7}$$

</details>

### Problem 11

Simplify: $\dfrac{3}{8}\times\dfrac{4}{3}+\dfrac{5}{8}$

<details><summary>Solution</summary>

Cancel the $3$ first:

$$\frac{4}{8}+\frac{5}{8}=\frac{4+5}{8}$$

</details>
