# Lesson 6.4: Complicated Fractions — Addition and Subtraction
*Fundamental Math / Course 2*

[Lesson 6](./06-fraction-addition.md) added fractions using equivalent fractions, and
[Lesson 6.3](./06.3-fraction-multiplication-division-reduction.md) handled products and
quotients. This lesson builds a clean method for adding several fractions with different
denominators, then combines it with multiplication.

**Rules for this class:** keep every sum and product in unevaluated form (write
$3\times7+2\times5$, not $31$) and use only the numbers already in the problem.

## 1. Same Denominator: Add the Numerators

$$\frac{7}{12}+\frac{5}{12}=\frac{7+5}{12}$$

The denominator names the size of the pieces and does not change. Subtraction is addition
of a negative, so it works the same way:

$$\frac{7}{15}-\frac{4}{15}+\frac{2}{15}=\frac{7-4+2}{15}$$

## 2. Different Denominators: Make Them Match

Pieces of different sizes cannot be added directly. Use $\dfrac{a}{b}=\dfrac{a\times c}{b\times c}$
to rewrite each fraction with the **same** denominator. The simplest common denominator is the
product of the two denominators:

$$\frac{2}{3}+\frac{4}{5}
=\frac{2\times5}{3\times5}+\frac{4\times3}{5\times3}
=\frac{2\times5+4\times3}{3\times5}$$

**Shortcut for two fractions:**

$$\frac{a}{b}+\frac{c}{d}=\frac{a\times d+c\times b}{b\times d}$$

Each numerator is multiplied by the *other* fraction's denominator ("cross-multiply, then add").

Subtraction uses the same pattern, with a minus sign:

$$\frac{3}{4}-\frac{2}{7}=\frac{3\times7-2\times4}{4\times7}$$

## 3. Denominators That Share a Factor

When denominators are written as products and share a factor, there is no need to repeat it.
Build the common denominator from every factor **once**, then multiply each numerator by
whatever factors its denominator is missing.

$$\frac{5}{6}+\frac{7}{6\times4}$$

The second denominator already contains $6$, so only the first fraction needs the missing
$4$:

$$=\frac{5\times4}{6\times4}+\frac{7}{6\times4}=\frac{5\times4+7}{6\times4}$$

Another case, where each denominator is missing a different factor:

$$\frac{1}{2\times3}+\frac{1}{3\times7}$$

The common denominator is $2\times3\times7$. The first fraction is missing $7$, the second
is missing $2$:

$$=\frac{1\times7+1\times2}{2\times3\times7}$$

## 4. Multiply First, Then Add

Order of operations still applies: products and quotients before sums and differences.
Rewrite the product as one fraction, then add.

$$\frac{2}{7}+\frac{3}{5}\times\frac{1}{7}=\frac{2}{7}+\frac{3\times1}{5\times7}$$

The first fraction is missing $5$:

$$=\frac{2\times5+3\times1}{5\times7}$$

## 5. Complex Fractions With a Sum Inside

A long fraction bar groups everything above it and everything below it. Combine the top into
one fraction, then divide by the bottom using Lesson 6.3:

$$\dfrac{\quad\dfrac{1}{3}+\dfrac{1}{4}\quad}{\quad\dfrac{1}{5}\quad}
=\frac{1\times4+1\times3}{3\times4}\div\frac{1}{5}
=\frac{(1\times4+1\times3)\times5}{3\times4\times1}$$

Keep the parentheses: the whole sum is multiplied by $5$.

## Reading Example 1: Three Fractions

**Example.** Write $\dfrac{3}{4}-\dfrac{1}{4\times5}-\dfrac{2}{5}$ as one fraction.

**Solution:**

The common denominator is $4\times5$. The first fraction is missing $5$, the second is
missing nothing, and the third is missing $4$:

$$\frac{3\times5}{4\times5}-\frac{1}{4\times5}-\frac{2\times4}{5\times4}=\frac{3\times5-1-2\times4}{4\times5}$$

$\square$

## Reading Example 2: Reduce, Then Add

**Example.** Simplify $\dfrac{3}{8}\times\dfrac{4}{3}+\dfrac{5}{8}$.

**Solution:**

Cancel the $3$ in the product:

$$\frac{3\times4}{8\times3}+\frac{5}{8}=\frac{4}{8}+\frac{5}{8}$$

Same denominator, so add the numerators:

$$\frac{4+5}{8}$$

$\square$

## Common Mistakes

### Adding denominators

$\dfrac{2}{3}+\dfrac{4}{5}\ne\dfrac{2+4}{3+5}$. The denominator is the piece size and is
kept, never added.

### Changing only the denominator

If the denominator is multiplied by $5$, the numerator must be multiplied by $5$ too.
Otherwise the fraction's value changes.

### Cancelling a term that is added

Only a **factor** (something multiplied) can be cancelled. A number that is *added* to
other terms cannot, even when it appears in both the numerator and the denominator. This
is completely wrong:

$$\frac{3+5}{3+7}\overset{\text{WRONG}}{=}\frac{\cancel{3}+5}{\cancel{3}+7}=\frac{5}{7}$$

Check with a case we can finish: $\dfrac{3+5}{3+7}=\dfrac{8}{10}$, which is not $\dfrac{5}{7}$.
The $3$ is one *term* of a sum, not a factor of the whole top or the whole bottom.

Cancelling is allowed only when the whole numerator and the whole denominator are products
containing the same factor:

$$\frac{3\times5}{3\times7}=\frac{5}{7}$$

If a sum is on top, a common factor must multiply the **entire** sum, for example
$\dfrac{3\times(5+2)}{3\times7}=\dfrac{5+2}{7}$.

### Dropping the parentheses

In $\dfrac{(1\times4+1\times3)\times5}{3\times4\times1}$ the parentheses are required;
without them only $1\times3$ would be multiplied by $5$.

## Class Practice 1: Unlike Denominators

**Problem.** Write $\dfrac{3}{5}+\dfrac{2}{7}$ as one fraction.

<details><summary>Solution</summary>

$$\frac{3\times7+2\times5}{5\times7}$$

</details>

## Class Practice 2: Subtraction

**Problem.** Write $\dfrac{4}{9}-\dfrac{5}{8}$ as one fraction.

<details><summary>Solution</summary>

$$\frac{4\times8-5\times9}{9\times8}$$

</details>

## Class Practice 3: Shared Factor

**Problem.** Write $\dfrac{5}{6}+\dfrac{7}{6\times5}$ as one fraction using the smallest
form of common denominator.

<details><summary>Solution</summary>

The first fraction is missing $5$:

$$\frac{5\times5+7}{6\times5}$$

</details>

## Class Practice 4: Multiply, Then Add

**Problem.** Write $\dfrac{2}{3}+\dfrac{4}{5}\times\dfrac{1}{3}$ as one fraction.

<details><summary>Solution</summary>

$$\frac{2}{3}+\frac{4\times1}{5\times3}=\frac{2\times5+4\times1}{5\times3}$$

</details>

## Class Practice 5: Sum Inside a Complex Fraction

**Problem.** Rewrite $\left(\dfrac{5}{6}-\dfrac{1}{6}\right)\div\dfrac{7}{9}$ as a single
fraction.

<details><summary>Solution</summary>

Combine the parentheses, then flip the divisor:

$$\frac{5-1}{6}\times\frac{9}{7}=\frac{(5-1)\times9}{6\times7}$$

</details>

## Key Takeaways

- Same denominator: keep it and add the numerators (subtraction is adding a negative).
- Different denominators: multiply top and bottom of each fraction by what its denominator
  is missing, then add.
- For two fractions: $\dfrac{a}{b}+\dfrac{c}{d}=\dfrac{a\times d+c\times b}{b\times d}$.
- Do products and quotients first, then sums.
- Never add denominators, and keep parentheses around a combined numerator.
