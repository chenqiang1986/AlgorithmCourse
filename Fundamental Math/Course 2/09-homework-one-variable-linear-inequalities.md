## Part D: Reasoning and Word Problems

### Problem 16

For each inequality, decide whether the solution is all real numbers or no solution.

1. $2x+1\leq2x+4$
2. $3x-2>3x+5$

<details><summary>Solution</summary>

For the first inequality, subtract $2x$ from both sides:

$$1\leq4$$

This is always true, so the solution is **all real numbers**.

For the second inequality, subtract $3x$ from both sides:

$$-2>5$$

This is never true, so there is **no solution**.

</details>

### Problem 17

A game requires at least $120$ points to advance. Jordan has $45$ points and earns $15$ points
per round. Write and solve an inequality for the number of rounds, $r$, Jordan needs.

<details><summary>Solution</summary>

“At least” means $\geq$:

$$15r+45\geq120$$
$$15r\geq75$$
$$r\geq5$$

Jordan needs at least **5 rounds**.

</details>

### Problem 18

A storage box can hold no more than $50$ pounds. It already contains $14$ pounds of books, and
each additional book weighs $3$ pounds. Write and solve an inequality for the number of
additional books, $b$, that can be added.

<details><summary>Solution</summary>

“No more than” means $\leq$:

$$3b+14\leq50$$
$$3b\leq36$$
$$b\leq12$$

At most **12 additional books** can be added.

</details>

### Problem 19

The temperature is $4^\circ\!\text{C}$ at noon and drops $3^\circ\!\text{C}$ each hour. Write
and solve an inequality for the number of hours $h$ until the temperature is below
$-8^\circ\!\text{C}$.

<details><summary>Solution</summary>

$$4-3h<-8$$
$$-3h<-12$$

Divide by $-3$ and flip the sign:

$$h>4$$

The temperature is below $-8^\circ\!\text{C}$ after more than $4$ hours. If only whole hours
are considered, it first happens after **5 hours**.

</details>

### Problem 20

Explain and correct the mistake:

$$-2x+6>14$$
$$-2x>8$$
$$x>-4$$

<details><summary>Solution</summary>

The last step divided by $-2$ but did not flip the inequality sign. The correct solution is:

$$-2x>8$$
$$x<-4$$

Use an open circle at $-4$ and shade left.

</details>
