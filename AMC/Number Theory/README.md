# AMC Number Theory
*AMC / Number Theory*

This folder contains an introductory 12-week number theory course for AMC-style problem
solving. The complete scope and sequence is in [00-syllabus.md](./00-syllabus.md).

## Lessons

1. [01-divisibility-and-congruence-modulo.md](./01-divisibility-and-congruence-modulo.md)
   Divisibility notation, division with remainder, congruence modulo $n$, and safe
   arithmetic with congruences.
2. [01-homework-divisibility-and-congruence.md](./01-homework-divisibility-and-congruence.md)
   Calculation practice and place-value proofs for divisibility tests modulo $3$, $9$,
   $11$, $7$, and $13$.
3. [02-primes-composites-and-prime-factorization.md](./02-primes-composites-and-prime-factorization.md)
   Prime and composite numbers, the role of $1$, square-root primality testing, and
   prime factorization using exponents.
4. [02-homework-primes-composites-and-prime-factorization.md](./02-homework-primes-composites-and-prime-factorization.md)
   Practice with factors, primality testing, prime factorizations, and reasoning from
   prime exponents.

Additional lessons will be added following the syllabus sequence.
