# D02 - scikit-learn Basics

This folder contains an introductory machine learning lesson using scikit-learn.

## Course Goals

In this module, we will learn:

1. What scikit-learn is and why it is useful
2. How machine learning code is usually organized into features and targets
3. How to split data into training and testing sets
4. How to train a basic `LinearRegression` model
5. How to make predictions and evaluate the result
6. How to read the full code flow of a simple model from start to finish

## Lessons

1. [01-linear-regression-overview.md](./01-linear-regression-overview.md)
   A first end-to-end walkthrough of training and testing a linear regression model in scikit-learn
2. [02-linear-regression-parameters.md](./02-linear-regression-parameters.md)
   A guided look at the main `LinearRegression` parameters and when changing them matters
3. [03-linear-regression-data-preprocess.md](./03-linear-regression-data-preprocess.md)
   How to prepare categorical values, dates, and differently scaled numeric columns before training linear regression

More lessons can be added later as the course grows.
